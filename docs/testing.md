# Testing Strategy

For current FamilyFoodOS work, follow the testing requirements in `AGENTS.md`,
the project operating manual, the explicit task, applicable scoped
instructions, and the current commands defined by the touched implementation.
A change is complete only when its scope is respected, relevant checks are run,
applicable smoke is completed or explained, and durable documentation/state is
updated when required.

`docs/pr-testing-and-smoke-rules.md` is an inherited CosmeticWorkshopOS testing
guide. Its generic safety and verification patterns may be consulted as legacy
reference when compatible, but its old PR numbering, domain smoke scenarios,
package checks, and mandatory prompt language are not current FamilyFoodOS
instructions.
