# Условия публикации первой партии

Статус: review proposal; текущий canonical registry и публикационная политика
не меняются. См. [DATA-CORPUS-V1](../../../docs/family-food/data-corpus-v1.md)
и [Nutrition](../../../docs/family-food/nutrition-core.md).

## 1. Источник углеводов — конкретная несовместимость

Книга2002 описывает усвояемые углеводы, преимущественно по разности без клетчатки;
метод отдельной строки может быть не установлен. Это не принятый CHOAVL
(mass-by-summation), и не CHOCDF с клетчаткой. Добавление клетчатки, вычитание
её из legacy carbohydrate или сумма source сахаров/крахмала не разрешены как
«исправление» метода.

Рекомендуемый отдельный контракт: хранить source-native наблюдение с method
`unspecified_with_book_general_method`, версией источника и статусом. Принятие
нового canonical показателя возможно только после определения method policy,
совместимости с целями и реакции Nutrition на несовместимые показатели.
Не присваивать всем строкам by-difference только по общему описанию книги.

Альтернатива: сохранить нынешний registry и допубликовывать только показатели,
совместимость которых доказана, оставляя углеводы unknown для неподдержанного
метода. Такая публикация не означает готовый рецепт к каждому сценарию Planner.
Никакая из этих альтернатив автоматически не принята данным PR.

## 2. Напечатанный ноль

Source legend: printed page23/pdf24, review ID `sc:book2002:legend:zero`.
Он означает ненахождение в пределах чувствительности метода, предел неизвестен.
Предлагаем сохранять literal0, state below_detection, usable value null и
неизвестный detection limit. Отдельный режим воспроизведения опубликованной
оценки может считать printed0 с явной версией политики и uncertainty, если
такой режим будет принят. Не использовать его как EXACT_ZERO или сертификат
отсутствия аллергена. Dash/missing никогда не конвертируется в0.

Это особенно существенно для сахара и масла: правдоподобный результат не
даёт права подменить смысл исходной ячейки.

## 3. Права и точное издание

Книга: Институт питания РАМН, редакторы И.М.Скурихин/В.А.Тутельян, ДеЛи принт,
2002, ISBN5-94343-028-8. Сохранённый PDF и review receipts входят во внешний
v0.3, hash `e9c302fea52547222b778a3313d876135190131a4f2a04bf59f9b0751a4388d5`.
University hosting не устанавливает лицензию на публичный bulk reuse.
В этом PR публикуются IDs/метаданные/решения; таблицы нутриентов и текст книги
не копируются. Production use disposition остаётся pending, а не объявляется
запрещённым или разрешённым без основания.

Повторная проверка20.09.2026: [карточка НЭБ](https://rusneb.ru/catalog/000199_000009_001844793/)
найдена поиском, прямое открытие вернуло403. Это не новое подтверждение лицензии.
[Официальная карточка Руссоль](https://russalt.ru/produkcziya/sol-pishhevaya-molotaya-jodirovannaya-sort-vysshij-pomol-%E2%84%961-2/)
подтверждает отдельный йодированный продукт; она не устанавливает полный
нутриентный профиль всех йодированных солей или право распространения книги.
Цены/наличие не собирались.

Нужен конкретный reuse disposition для ограниченного набора фактов либо
лицензированная выгрузка/разрешение, определяющее машинную обработку, внутреннее
хранение, коммерческое применение и публичную публикацию производных данных.
Если ранее полученное разрешение существует — проверить документ и его scope;
не требовать новое автоматически. В противном случае ниже готов текст запроса.
Никаких обращений не отправлено.

### Черновик запроса издателю/правообладателю

Просим уточнить условия использования данных из справочника «Химический состав
российских пищевых продуктов», издание2002, ISBN5-94343-028-8, в сервисе
FamilyFoodOS. Планируется извлечение структурированных фактических показателей
для ограниченного перечня продуктов с указанием источника, версии и единиц.

Просим указать допустимые условия внутреннего хранения исходного экземпляра,
машинной обработки, коммерческого расчётного использования и распространения
производных структурированных данных. Если доступна лицензированная актуальная
выгрузка, просим предоставить описание состава полей, методик, версии и условий
получения. Полный текст книги, изображения страниц и оформление в интерфейсе
публиковать не планируется. Покупка и отправка этого запроса требуют отдельного
поручения пользователя.

## 4. Конкретный следующий набор

Для дальнейшего точного raw/edible input review приоритетны сахар10.1.1,
морковь8.1.5.1, капуста8.1.2.1, свёкла8.1.5.12 и рисовая крупа6.5.3.
Это пять групп с идентифицированным source record, а не принятая публикационная
партия. В generated перечислены все затронутые occurrence IDs; для каждого
следует доказать место измерения массы относительно очистки/термообработки.

Лук, картофель и масло могут потребовать отдельной generic food identity вместо
переиспользования более узкого текущего профиля. Молоко/масло/мука требуют
выбора подтверждённой формы; для сметаны нужен15% профиль. Не выбирать варианты
только ради уменьшения data debt. Йодированная соль остаётся самостоятельной
зависимостью многих блюд и не может исчезнуть из состава для закрытия gate.

После закрытия form/rights/method решений publication payload обязан связывать
FoodIngredient → FoodNutritionProfile → sealed NutrientVector → ATOMIC;
проверки fresh/repeat/conflict/rollback выполняются через существующие сервисы.
Этот PR таких записей не создаёт и не утверждает, что эти условия уже закрыты.
